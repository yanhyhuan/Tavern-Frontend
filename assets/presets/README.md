# 内置预设

V1.0.1 以龙血玄黄数据库 1.3.6 自带 8 表为基线，保留原前端界面和预设管理方式。旧骰子 v4.3 模板不再作为运行资源。

| 类型 | 内置内容与适配方式 |
| --- | --- |
| 检定 | CoC7、CoC7-成长、DND5e、Fate、PbtA、三角机构；保留原算式，使用手动数值、独立聊天属性或 v4.5 原属性列。 |
| 属性 | 简化 COC、简化 DND；默认模板下使用扩展自己的聊天属性，不新增数据库列；v4.5 有真实属性列时继续公开 CRUD。 |
| 交互 | 对应默认角色、背包、技能、任务；保留自定义模板关键词配置。 |
| 仪表盘 | 主角近况和所在地点、NPC 在场状态、背包类别和数量、叙事任务进度；缺少的状态/品质列不按旧位置猜测。 |
| 渲染 | 默认身份、人际关系、叙事文本及徽章规则；不要求增加属性或地图列。 |
| 模板检验 | 数据库默认 8 表为默认，v4.5 可选；唯一显示名/别名与业务列兼容时允许不同稳定 key 和 SQL 名。 |
| 数据验证 | 针对默认表真实字段的必填、在场枚举、任务类型、物品数量、纪要编号与时间格式等规则。任务进度允许叙事文本。 |
| 表格正则 | 清除极端词、去八股、关系分隔空白；默认只作用于叙事或人际关系列，不覆盖姓名、row_id、数量、编号和时间。 |
| 骰子商城 | 6 卡池、95 件物品；数据库默认模板下装备与道具统一写入背包，品质保存于奖励描述标记。 |

预设在原界面相应管理区内选择、复制、导出。默认正则包含自动执行规则，首次请使用合成聊天，检查启用状态和预览效果。切换检定/属性预设不再隐式整模板导入。

地图使用已记录的全局/角色位置生成只读概览，未知地区不作推断；默认模板没有独立地图元素和检定建议表，这些表专用内容只在实际存在时展示。

角色头像和图标仍支持用户导入与管理，不包含用户头像或私人配置。配置方案、头像、图标、数据库数据和独立聊天属性属于不同存储范围，迁移前请按各自入口导出。

模板在 [templates](../templates/) 中。运行界面只提供“数据库默认 1.3.6”和“v4.5 可选兼容”；下载不自动导入或修改现有表。

实现见 [index.ts](../../src/骰子系统/index.ts)、[默认预设字段](../../src/骰子系统/database-default-presets.ts) 和 [商城内容](../../src/骰子系统/gacha-items.ts)。完整功能与验收边界见 [功能适配](../../docs/FEATURE-COMPATIBILITY.md) 和 [测试记录](../../docs/TESTING.md)。
