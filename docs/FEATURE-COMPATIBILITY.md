# 默认 8 表与功能兼容

本版按龙血玄黄数据库 1.3.6 的默认 8 表配置内置功能。默认模板与可选 v4.5 都是固定文件；下载不会导入或修改聊天。

| 功能 | 数据库默认模板的行为 |
| --- | --- |
| 模板检查 | 默认检查 8 表及其业务列；v4.5 可单独选择 12 表检验。名称、显式别名和业务结构用于识别，key/SQL 物理表名可以不同。 |
| 正则转换 | 默认只作用于已有叙事和关系字段；更改通过公开 CRUD 保存并回读核验，row_id、锁定和无变化的单元格保留。 |
| 人物和仪表盘 | 使用主角信息表、重要角色表的真实姓名、近况、所在地点和关系等字段。主角表默认没有人际关系列。 |
| 地点 | 根据全局数据及角色已记录的位置显示只读概览；不创建地图表或虚构地点。 |
| 物品与装备 | 默认共用背包物品表；新奖励品质写在描述/效果的标记中，默认模板没有单独品质列或装备表。 |
| 任务与纪要 | 任务当前进度使用原始叙事文本，不要求百分比或旧状态列；纪要使用数据库原有字段。 |
| 属性和检定 | 默认主角和角色表没有数值属性列；扩展属性使用独立的本机聊天属性存储，和数据库聊天导出是不同的数据范围。v4.5 若提供属性列，沿用这些列。 |
| 检定建议 | 默认没有独立检定建议表；基础检定配置仍可使用，依赖该表的建议入口需要相应表。 |

默认模板与 v4.5 的同名或近义表有真实列和约束差异；检查出不兼容时会停止导出新增候选，不会改现有表来匹配另一个模板。候选为新增表片段，须在数据库中手动添加和校验。

默认模板的角色属性按聊天、隔离环境、表 key/uid 和稳定 row_id 保存在本机浏览器中。通过“配置方案与备份 → 当前聊天属性备份”单独导出、导入；数据库备份和配置方案均不包含它们。导入只接受相同聊天与隔离环境，角色行必须存在、身份唯一且未锁定；身份、锁或格式校验失败时整批不提交。写入后若读回校验失败，将报告无法确认保存，需重新读取核对。v4.5 的数据库属性列不属于这份备份。

自动测试使用合成数据；2026-11-06 用户反馈真实 TauriTavern 安装与关闭重开聊天正常，此两项记录为用户实机验证通过。数据库公开 CRUD 没有预期聊天或取消参数，无法保证已经进入数据库的调用在聊天切换后被撤销；请等待保存结束再切换。详细结果和测试方法见 `docs/TESTING.md`。

另有一次性内存模拟验证消息注入的同聊成功、切聊后停止及 API 失败传播；这三项未纳入持续回归测试，也不代表真实宿主验收。
